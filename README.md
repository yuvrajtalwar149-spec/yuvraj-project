
# Fast Food Calorie Prediction

## Project Overview
Machine Learning project for calorie prediction using
Random Forest Regressor.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Dataset Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Preprocessing
5. Model Training
6. Model Evaluation

## Evaluation Metrics
- Mean Squared Error (MSE)
- R-squared (R2) Score
